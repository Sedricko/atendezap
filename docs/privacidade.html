Política de Privacidade do AtendeZap

Última atualização: 25 de outubro de 2026 · vale para a extensão AtendeZap para Chrome e Edge

1. Resumo

O AtendeZap é uma extensão que ajuda a atender clientes no WhatsApp Web (respostas rápidas, assinatura, organização de conversas e grupos e um assistente de inteligência artificial opcional). A extensão não tem servidor próprio. Os dados ficam no seu computador e só saem dele para serviços que você mesmo configura: a API do Google Gemini, com a sua chave, e as suas planilhas Google, com o seu Apps Script. Não vendemos, não compartilhamos e não usamos dados para publicidade.

2. Quais dados a extensão acessa

  • Conteúdo do WhatsApp Web que aparece no seu navegador: nomes, números, mensagens e grupos das conversas. A extensão usa esses dados para mostrar as funções na tela (por exemplo: quem está aguardando resposta, pedidos para entrar em grupos).
  • As suas configurações: respostas rápidas, assinatura, categorias, preferências do painel.
  • A sua chave da API do Gemini, se você ativar o assistente de IA.
  • Um identificador aleatório do computador, criado pela própria extensão, e o tipo de sistema e a versão do navegador (por exemplo: "Windows · Chrome 130"). Eles só são usados se você conectar a planilha da equipe.

3. Onde os dados ficam

Tudo é guardado no armazenamento local da extensão, no seu computador (chrome.storage.local). Backups, exportações e pacotes de diagnóstico só são gerados quando você pede e são baixados como arquivo no seu próprio computador. Backups e pacotes de diagnóstico nunca incluem a chave da IA nem o convite da equipe. Os pacotes de diagnóstico não incluem mensagens, contatos nem números de telefone.

4. Quando os dados saem do seu computador

  • Google Gemini (API de IA): só se você ativar o assistente e colocar a sua chave. Os textos necessários para gerar a sugestão (por exemplo, as mensagens do cliente na conversa em que o robô atua) são enviados para generativelanguage.googleapis.com com a sua chave. Esse envio segue os termos e a política de privacidade do Google para a API Gemini. O Atendente IA começa desligado e pede o seu aceite antes de funcionar.
  • As suas planilhas Google (Apps Script): só se você colar o endereço de um script seu. A extensão aceita apenas endereços https://script.google.com/macros/s/…/exec. Para a planilha de frete e IA podem ser enviados a lista de cargas, perguntas e respostas para a memória da IA e o estado do robô. Para a planilha da equipe vão o código de convite, o identificador aleatório do computador, o tipo de sistema e navegador e a versão da extensão. Essas planilhas pertencem a você ou à sua empresa.

Nenhum outro envio acontece. A extensão não usa ferramentas de estatística, rastreamento nem anúncios.

5. O que a extensão não faz

  • Não vende nem transfere dados a terceiros.
  • Não usa dados para publicidade, perfil de crédito nem qualquer fim que não seja a própria função da extensão.
  • Não abre, salva nem exporta mensagens de visualização única.
  • Não tem acesso a nenhum site além do WhatsApp Web e dos serviços do Google listados acima.

6. Uso de dados de clientes (LGPD)

Quem usa a extensão para atender os próprios clientes é o controlador desses dados. Se você ativar a IA, avise os seus clientes quando a lei exigir, já que as mensagens deles serão processadas pela API do Google.

7. Como apagar os dados

Remover a extensão do navegador apaga todos os dados locais dela. Os dados enviados às suas planilhas podem ser apagados direto nelas. Os dados processados pela API Gemini seguem as regras de retenção do Google.
